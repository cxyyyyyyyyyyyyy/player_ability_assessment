# 绿茵慧眼 · 球员能力评估系统 立项报告

## 一、项目背景与目标

**背景：**
足球领域对球员的评价长期依赖教练或球探的主观经验，普通球迷与业余球员很难获得量化、可解释的能力参考。市面上的专业球探系统（如 SciSports）不对大众开放，游戏评分（如 FIFA）虽量化但缺乏解释性与生涯维度。

**面向场景：**
- 球员/球迷输入一名球员的基本信息，希望快速了解其能力结构、风格类型、巅峰潜力与合理生涯规划；
- 团队项目课程要求：五名成员协作完成一个「数据采集 → 建模 → 可视化 → Web 交付」的完整闭环项目。

**预期目标：**
1. 实现可运行的球员能力评估 Web 系统：输入球员信息，一键输出**预测潜力、能力画像、风格定位、生涯规划建议与对标球员**；
2. 选用公开足球数据集，完成数据清洗、特征工程与三类核心模型（聚类 / 回归预测 / 相似度匹配）；
3. 按课程要求完成每日进度记录（daily / prompts / todos）与期末三份文档，全员参与分工。

## 二、项目简介

绿茵慧眼 · 球员能力评估系统：输入球员信息，输出潜力预测、能力画像、风格定位、生涯规划建议与对标球员。

- 潜力预测：随机森林回归 + 年龄-能力成长曲线；
- 能力画像：六维能力（速度/射门/传球/盘带/防守/身体）雷达展示；
- 风格定位：KMeans 聚类 + PCA 降维可视化（速度冲击型 / 技术组织型 / 后防屏障型 / 锋线终结型 等）；
- 生涯规划：规则引擎（可选 LLM 增强）生成可解释建议；
- 对标球员：余弦相似度匹配最接近的知名球星。

## 三、技术方案

- 后端：Python / FastAPI / scikit-learn / pandas
- 前端：原生 HTML / CSS / JavaScript（由后端统一托管静态页面）
- 数据：European Soccer Database 提取的球星库与球员池（CSV）
- OCR：RapidOCR（上传球员图片自动识别信息）
- 可选增强：OpenAI 兼容大模型接口生成球探报告文本
