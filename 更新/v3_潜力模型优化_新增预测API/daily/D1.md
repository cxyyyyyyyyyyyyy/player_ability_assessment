## 遇到的问题与解决
- 中文 commit message 在 Windows PowerShell 下乱码：用 `chcp 65001` 切换 UTF-8 后 `git commit --amend` 重写提交，再 `git push --force-with-lease` 覆盖远程
- `database.sqlite`（313MB）超过 GitHub 100MB 限制：确认它只是原始数据源（仅被提取脚本使用一次）、运行时只读 CSV，加入 `.gitignore` 不上传，不影响功能
