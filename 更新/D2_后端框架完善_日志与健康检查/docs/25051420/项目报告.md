# 绿茵慧眼 · 球员能力评估系统 项目报告

## 一、项目概述

本系统基于 Python 构建了一个球员能力评估与生涯规划工具：用户输入球员信息（或直接选择球星库、上传球员卡图片），系统返回**预测潜力、能力画像、风格定位、生涯规划建议与对标球员**五部分报告。项目以公开足球数据为原料，实现了「数据加载 → 特征工程 → 三类模型 → REST API → Web 页面」的完整链路，前后端由 FastAPI 统一托管。

## 二、系统设计

### 2.1 总体架构

```
frontend/（HTML/CSS/JS 静态页，后端托管）
   │  HTTP
backend/（FastAPI）
   ├── main.py        # 入口：lifespan 启动编排（Registry 加载数据+训练模型）
   ├── config.py      # 全局配置：路径/参数/六维字段/位置映射/应用元信息
   ├── data/          # 数据加载层（球员池、球星库、Schema）
   ├── models/        # 模型层：聚类、潜力预测、相似度
   ├── agent/         # 评估引擎与生涯规划建议
   ├── services/      # OCR 识别等服务
   └── api/routes.py  # REST API
```

### 2.2 关键设计

- **Registry 生命周期**：应用启动时统一加载数据、训练模型并挂到 `app.state`，路由只读不重训；
- **统一日志**：logging 覆盖启动 / 数据加载 / 模型训练 / 关闭全流程，记录加载耗时；
- **配置集中化**：路径、规模、六维能力顺序、位置映射、应用名版本与日志级别统一收敛于 `config.py`；
- **后端托管前端**：根路径返回 `index.html`，静态目录挂载于 API 路由之后，保证 `/api/*` 优先命中。

## 三、核心算法与实现

### 3.1 数据与特征

- 六维能力：`pace / shooting / passing / dribbling / defending / physical`（全局统一顺序）；
- 位置映射：细位置（LB/RB/CDM/CAM/LW…）归一为六大主位置 `GK/CB/FB/CM/CAM/W/ST`；
- 球员池约 1800 人（覆盖位置 / 年龄段 / 能力段），球星库 32 名用于对标。

### 3.2 潜力预测（随机森林回归）

- 特征：年龄、当前能力、六维能力 + 主位置 one-hot；
- 输出：潜力峰值 + 16~36 岁年龄-能力成长曲线（31 岁为参考巅峰年龄，过巅峰后按衰减系数下滑）；
- 模型评估：报告 R² 与 RMSE，并作为 `/api/health` 指标对外暴露。

### 3.3 风格聚类（KMeans + PCA）

- 以六维 + overall 为特征聚类，PCA 降维到二维用于前端散点可视化；
- 产出可命名的风格标签（速度冲击型 / 技术组织型 / 后防屏障型 / 锋线终结型 等）。

### 3.4 对标匹配（余弦相似度）

- 在位置约束内用能力向量余弦相似度挑选最接近的知名球星，作为「我的模板球员」。

### 3.5 生涯规划建议

- 规则引擎为主（依据位置、年龄段、潜力余量生成建议），可选配置 OpenAI 兼容 LLM 生成更自然的球探报告文本；未配置时系统照常运行。

### 3.6 OCR 识别

- 上传球员卡片 / 截图，RapidOCR 提取文本后解析姓名与能力，进入评估流程。

## 四、结果与展示

### 4.1 已上线接口

| 接口 | 说明 |
|------|------|
| `GET /api/health` | 健康检查（应用名 / 版本 / 池规模 / 聚类数 / 潜力模型 R²） |
| `GET /api/stars` | 内置 32 名球星 |
| `GET /api/players?search=&limit=` | 球员库搜索 |
| `GET /api/cluster-map` | 聚类散点 + 汇总 |
| `POST /api/evaluate` | 球员评估（按名字或自定义球员） |
| `POST /api/recognize` | 图片 OCR 识别 |

### 4.2 评估报告结构

一名球员的完整输出 = 能力画像（雷达） + 风格定位（所属聚类） + 潜力预测（峰值与成长曲线） + 生涯规划建议 + 对标球员。

## 五、总结与展望

- **完成情况**：R1~R11 需求全部实现，前后端联调通过，按课程要求维护版本快照与过程记录；
- **不足**：球员池数据为规则生成的合成样本，真实度有限（可替换为 Kaggle FIFA 数据集）；模型未做在线学习；
- **展望**：接入真实比赛数据与可视化排位、增加位置适配推荐、支持批量导入、引入更强的开源模型提升建议质量。

> 本报告按版本迭代更新：v1 基础框架 → v2 日志与健康检查 → v3 潜力模型优化 → v4 部署优化，最终版以 v4 目录为准。
